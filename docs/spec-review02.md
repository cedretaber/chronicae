## A. まだ曖昧・未定義の部分

### A-1. シード変換の hash 関数が未定義（21.3.2）

「文字列を hash して 32bit unsigned integer に変換する」とあるが、使用する hash アルゴリズムが指定されていない。

RNG の決定性はシード変換の一貫性に依存するため、hash 関数が実装者任せになると「同じ seed 文字列でも実装によって異なるシーケンスになる」リスクがある。

推奨：FNV-1a (32bit) または djb2 など、軽量で広く知られたアルゴリズムをひとつ明示する。

### A-2. `basePlotSuccess` の値が未記載（21.8.4）

成功率の基本式に `basePlotSuccess` が登場するが、値が書かれていない。

SimulationConfig に入れるとしても、デフォルト値の目安が必要。他の補正値のスケールから推測すると 30〜50% 程度が妥当と思われるが、明示されていない。

### A-3. 補充判定が「毎年1月のみ」では壊滅後に空白期間が生じる（21.11.2）

「毎年1月、各 House について人物数を確認する」とあるが、反乱失敗で家が壊滅した場合、最大11ヶ月間 member が 0 のままになりうる。

この状態では：

- SuccessionSystem が headId を更新できない
- AppointmentSystem の候補者がいない
- IntegrityCheck に引っかかる可能性がある

対応案：「生存 member が 0 になった tick で即時最低1名を補充する」例外条件を追記する。

### A-4. 格子 8×5 の seed province 配置の具体条件が未定義（21.13.2〜21.13.3）

「互いに離れた seed province を選ぶ」とあるが、「離れた」の具体的な条件（最小マンハッタン距離など）が定義されていない。

3国家の seed が偶然近くに配置されると、flood fill の結果が極端に偏り、1国家が大半のプロヴィンスを取得するケースが生じうる。

推奨：seed province 間の最小距離を格子座標で指定する（例：「互いのマンハッタン距離が 5 以上になるまで再抽選する」）。

### A-5. `adminPower` を保存値にするか導出値にするかが未決定（21.14.3）

「selector で計算する案を推奨する」としつつ「実装簡略化のため保存値として残してもよい」と両案が並立している。

Phase 1 の型定義時にどちらかを選ばないと、selector と保存値の両方を実装するか、後から型を変える必要が生じる。

推奨：Phase 1 では保存値として残し、Phase 3 以降で selector 化する、と明示して判断を確定させる。

## B. 新たに気づいた小さな不整合

### B-1. 21.19.4 で Person.role を「削除候補」としているが、21.6.1 では既に「原則として持たない」と断言している

表現の強さが節によって異なる。v0.2 への統合時に「削除する」と一本化する。

### B-2. 21.11.3 の新生人物の stats / traits が "random stats / random traits" のままで値域が書かれていない

21.13.6 の初期パラメータ範囲と同じ範囲を使うのか、補充人物には別の範囲（例：若者は martial が高めなど）を使うのかが不明。

補充人物も 21.13.6 の範囲に従うと明記するだけで十分。

### B-3. Plot の `power` / `secrecy` / `risk` の初期値算出方法が未定義（21.8.2）

Plot 型に `power: number`、`secrecy: number`、`risk: number` があるが、陰謀開始時にこれらをどう決めるかが書かれていない。

leader の stats や traits から計算するのか、固定値なのか、PlotSystem の説明に追記が必要。

### B-4. `durationMonths` の決め方が未定義（21.8.1〜21.8.2）

「3〜12か月程度」とあるが、具体的にどう決めるか（固定値？ランダム？陰謀種別によって異なる？）が書かれていない。

### B-5. rulerHouse の交代（RULER_HOUSE_CHANGED）の処理が未定義

反乱成功の結果として「新国家として独立」と「rulerHouse の交代」の2パターンがあるとされているが、21.10 では「新国家として独立」のみが具体化されている。

RULER_HOUSE_CHANGED の場合の処理（旧 rulerHouse の扱い、treasury の継続、legitimacy への影響など）が未定義。
