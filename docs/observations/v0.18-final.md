## バランス上の所感 (user との対話用 input — 修正は本セッションでは行わない)

### 1. escalation 経路が支配的

DIPLOMATIC_PLAY_SETTLED 90 件に対し ESCALATED 1123 件、RESOLVED_BY_CONFLICT 920 件。
妥協で終わるのは 6% 弱で、決裂してから武力衝突に発展するのが支配的経路。

仕様 §10.5 で言及されている設定:
- `diplomaticPlaySettlementThreshold = 60`
- `diplomaticPlayEscalationThreshold = 40`

escalation の閾値が settlement より低い → 緊張が積み上がる方が先に発生しやすい。
ユーザーと検討すべき: 「妥協が常態、escalation が例外」となる balance を目指すか、現状の「軍事威圧経路が主、外交妥協は副次」のままにするか。

### 2. land_transfer_demand 圧倒、land_purchase 控えめ

LAND_CONTRACT_TRANSFERRED 372 件 (主に demand / war 由来) に対し LAND_CONTRACT_PURCHASED は 38 件 (10%)。
acquire_land Intent → land_purchase 経路は (acquirer rich + 同 rank + 同 grantor + treasury が price 以上) の条件が厳しく、ほとんどが land_transfer_demand に倒れる。

ユーザーと検討すべき: 平和的 Province 売買をもっと観察したいなら、land_purchase 条件 (同 rank・同 grantor) を緩和する余地。

### 3. WAR_WON / WAR_LOST は同数 (当然)

各 conflict で attacker / defender 視点の 2 種 event を発火しているため対称。

### 4. revolt の分布

210 NEGOTIATION_STARTED → settled 52 / suppressed 147 / established 9 / 残り (= 失効 cancel) 約 2.
独立は 4% と低めだが、観察可能なレベルで発生している。

### 5. Intent 創出から Play 化への変換率

ACTOR_INTENT_CREATED 2024 → ACTOR_INTENT_CONVERTED 1525 (75%)。
残り 25% は重複防止 (active Play 既存) や条件不成立で expired。妥当と言える。

### Stage F での balance 観察

統合により以下が改善:

1. **outcome event の三分化が可視化された**: PURCHASED (補償あり妥協) / CEDED (補償なし妥協) / CONQUERED (武力奪取) でログから経路が判別可能になった
2. **経路固定の歪みが解消**: 旧 Stage E では land_purchase は cancelled で終わるしかなかったが、Stage F では同じ Play が交渉途中で escalation して戦争化する経路が可能になった

ただし新しい balance 課題が見えた:

3. **LAND_CONTRACT_CEDED = 0 件**: 補償なし要求 (acquire_land 購入条件不成立) では acceptanceScore がほぼ常に負 → settlement に届かず escalation/deadline に流れる。設計通りだが「軍事威圧での無償譲渡」が成立する余地が欲しい場合は `claimInitiatorPressureFactor` を上げる or `claimDefenderResistFactor` を下げる調整が必要
4. **DIPLOMATIC_PLAY_FAILED = 0 件**: deadline で progress=tension の同点 failed 経路に実質届かない。Stage E の 465 件から完全消失 — settlement / escalation のいずれかに必ず流れる構造になった (善し悪しは要議論)
5. **戦争比率が上昇**: WAR_WON 764 → 967 件 (+27%)。経路固定が外れたことで「最初は購入交渉、後で戦争に発展」が頻発しているのかも

### バランス調整セッションで議論したいポイント (Stage F 版)

1. **CEDED 経路を成立させるか**: `claimInitiatorPressureFactor` (0.1) を上げる、または `claimOfferedPriceFactor` を下げて補償なし要求でも acceptance が稼ぎやすくする
2. **PURCHASED を増やすか**: provinceValue / prestigeLoss の penalty を下げて settlement に届きやすくする
3. **escalation 抑制**: `diplomaticPlayEscalationThreshold` (40) を上げる / `claimDefenderResistFactor` を下げて tension の積み上げを遅らせる
4. **戦争頻度の妥当性**: 4 seed × 300 年で WAR_WON 967 件 (年あたり ~0.8 件/seed) は観察対象として「歴史らしい」か

これらは数値調整なので、ユーザーと一緒に観察 report を見ながら決める。
