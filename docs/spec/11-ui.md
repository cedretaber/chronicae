# 11. UI 構成

- **UnifiedMap（v0.20.2）**: 単一の SVG Voronoi マップ。zoom level に応じて State / Province の表示強度を自動切替
  - **Far zoom（State レベル）**: Province セルを State の dominant polity 色で統一表示。State 名 + 人口 + unrest ラベル。State クリック → そのエリアにスムーズズームイン
  - **Medium zoom（遷移）**: Province 単位の polity 色。Province 名ラベル・アイコン（小）・neighbor edge を表示。Province クリック → DetailPanel を開く
  - **Near zoom（Province 詳細）**: Province アイコン（都市/農村 + 城/荘園バッジ）フルサイズ表示。Province クリック → DetailPanel を開く。ホバーでツールチップ（名前/State/Polity/人口/unrest/Holdings数）
  - セル色表現: 薄い半透明 fill + 枠線に polity 色（地図の雰囲気を保持）
  - 外枠: ocean ダミー点（Province 群の凸包外側に配置）による不規則な輪郭
  - mapView 切替（T/R/H/%/!）: terminal polity / root polity / owner house / house share / unrest heatmap
  - highlight tier: DetailPanel で Polity/House 選択時に関連 Province をハイライト（direct/indirect/none）
  - ズームコントロール: +/-/reset ボタン（左下）
  - **旧二段階マップ（StateMap + ProvinceMap）は v0.20.2 で廃止**。ReactFlow (`@xyflow/react`) も撤去済み
- **Sidebar**: 人物一覧。重要度スコア順。ウォッチリスト対応
- **DetailPanel**: 選択エンティティ（Province / Polity / House / Person / PopGroup）の詳細表示
  - **ヘッダー画像**（v0.33: terrain/設備連動。`app/utils/assetHash.ts`）: Province / Holding の詳細ヘッダー（および Province 内 Holding カード）の画像を内容に応じて選択する。
    - Province（terrain 5 × 水状態 4 = 20 枚）: terrain（平野/森林/丘陵/山岳/湿地）と水状態を組み合わせる。水状態は「沿岸（coastal）」と「河川（major_river または lake）」の独立 2 軸（なし / 河川 / 沿岸 / 沿岸＋河川）。該当画像が無ければ terrain ベースへフォールバック。
    - Holding（荘園 2 + 都市 4 = 6 枚）: 荘園は牧畜（pastoral）の level が農地系（field_system / irrigation の最大）を上回るときのみ「牧畜」、それ以外は「農地」（設備なしも農地が既定）。都市は market & workshop 両方→「大都市」/ market のみ→「市場」/ workshop のみ→「工房」/ どちらも無し→「基本」。`storage` / `transport`（生産品質系）は画像選択に用いない。
  - ProvinceDetail:
    - **Holdings** セクション (v0.20 / v0.25 代官情報拡張 / v0.27 Improvement 表示): 各 Holding をカードで表示。name / kind badge (manor: 緑, city: 琥珀) / development（getHoldingDevelopment selector 経由）/ polityControl / landQuality / weight / per-Holding LandContract chain (各 grantee Polity をリンク付きで表示) / **Improvements**（v0.27: フレーバー名を主表示、カテゴリ+レベルを括弧内に補助表示。例: `三圃制農地 （農業基盤 Lv.2）`）/ **active develop_holding Project**（v0.27: stage / progress / budget 表示）/ Bailiff 詳細:
      - 代官名（person リンク）/ placeholder / vacant
      - BailiffPolicy（色分け: passive=灰, loyal_remittance=青, profit_seeking=橙, protect_residents=緑）
      - localExtractionRate / collectionEfficiency / bailiffFeeRate / totalBurdenRate / collectionFrictionBurdenRate（%表示）
      - 直近 Task status（completed=緑, none=灰）
      - POP→代官平均 Attitude（affection / respect）
    - **Population** セクション: habitability / Carrying Capacity / Total Population / Pop. Pressure（90% 超で赤表示）/ Avg Wealth / Unrest（60 超で赤表示）/ Production / Polity Manpower
    - **POP Groups** セクション: class 別に size / wealth / unrest（60 超で赤表示）を一覧表示。各 POP カードはクリッカブルで PopGroupDetail へ遷移（v0.11）
    - **Revolt Risk** セクション: class 別反乱傾向値（Peasants / Townsmen / Nobles）
    - development / polityControl は Holding の weight 加重平均で Province レベルに集約表示
  - PolityDetail（v0.12 / v0.15 更新）:
    - 基本情報: Ruler（人物リンク）/ Royal House（getPolityLeaderHouse）/ Dominant House（getDominantPolityHouse）/ 首都 / Legitimacy / Treasury / Military Power
    - **Administration** セクション: Capacity / Load / Efficiency（getAdministrative* セレクター）
    - **Roles** セクション: leader / administrator / treasurer / military / advisor の担当者リンク。各役職で `getActiveOfficeHolders` の全 holder を縦に表示（v0.21: 1人目だけでなく全員を表示）。空席は「—」。rank で許可されない役職は holder 0 で「—」表示
    - **Top Shareholders** セクション: Polity Share 上位 5 holder と割合。通常は House リンクで表示するが、§17 commonwealth / 独裁者・僭主による Person holder は Person リンク + 識別マーク（★）で表示する
    - **Houses with land here** リスト（v0.15）: その Polity に Province を 1 つ以上持つ active House を、Polity 内 Province 数とともに表示。primary がここでない House には「non-primary」マーカーを付ける
    - **Current Goal** セクション（v0.22）: GoalKind（i18n）/ DecisionReason 一覧 / progress / targetProgress
    - **Active Aim** セクション（v0.22）: AimKind（i18n）/ progress / targetProgress / deadline
    - **Active Task** セクション（v0.23）: TaskKind / effort / 担当者
  - HouseDetail（v0.12 / v0.32 更新）:
    - 基本情報: Leader（getHouseLeader）/ 本拠地 / Province 数 / Wealth / Prestige / Military
    - **Offices** セクション: administrator / treasurer / military / advisor の担当者リンク（空席は「—」）
    - **Top Shareholders** セクション: House Share 上位 5 Person と割合
    - **Clan** セクション（v0.32）: 所属 Clan 名（クリックで ClanDetail 遷移）/ Clan 内の立場（root / descendant）
    - **Current Goal** セクション（v0.22）: GoalKind（i18n）/ DecisionReason 一覧 / progress / targetProgress
    - **Active Aim** セクション（v0.22）: AimKind（i18n）/ progress / targetProgress / deadline
    - **Active Task** セクション（v0.23）: TaskKind / effort / 担当者
  - PersonDetail（v0.12 / v0.15 / v0.23 更新）:
    - 基本情報: Age / House / Sex / Birth Status / Wealth（v0.15: Country フィールド廃止、Relevant Polities へ）
    - **Life Goal** セクション（v0.23）: PersonGoalKind（i18n）/ fulfillment（currentFulfillment / 100）
    - **Current Pursuit** セクション（v0.23）: active PersonAim（AimKind / progress / deadline / waiting 状態表示）
    - **Assigned Tasks** セクション（v0.23）: effectivePriority 降順で表示。各 Task に kind / effort / P:値 / target 名（owner の house/polity 名付き）
    - **Recent Activities** セクション（v0.23 / v0.27 更新）: PersonActivityLog 直近 5 件。TaskActivityLog（week / taskKind / outcome）と ProjectActivityLog（week / projectKind / kind、params に improvementKind / targetLevel / holdingId があれば併記）を kind で分岐表示。i18n key: `activity.project_completed` / `activity.project_failed`
    - **Offices** セクション: Polity と House でグループ分け、役職重要度順（leader → administrator → treasurer → military → advisor）。代官職（HoldingOfficeAssignment）を持つ場合は任地 Province 名リンクと BailiffPolicy（色分け: passive=灰, loyal_remittance=青, profit_seeking=橙, protect_residents=緑）を表示（v0.25）
    - Stats / Traits / Family リンク / **Attitudes セクション**（v0.11）
  - **PopGroupDetail**（v0.11）: size / wealth / unrest（60 超で赤表示）/ 所属 Province リンク / **Attitudes セクション**
  - ClanDetail（v0.32）:
    - ヘッダー: Clan 名（nameSourceHouseId の House 名から派生）/ active or extinct バッジ
    - 基本情報: ID / 成立日 / root House（リンク）/ founder（リンク、存在する場合）
    - 統計: active House 数 / extinct House 数 / 生存人数 / 総資産 / 総威信 / 支配家門数
    - 所属家門一覧: root House（ラベル付き）→ active descendant → extinct descendant（dimmed）。上限 10 件 + "+N more"
  - DiplomaticPlayDetail（v0.23 拡張）: initiator / target の delegate 名、preparation / leverage / commitment パラメータ、active Task 一覧、tension / progress
- **EventLog**: Chronicle（major/critical）と全イベントの 2 ビュー + Timeline（年別グループ）
  - i18n 対応（v0.21）: イベント種別ラベルをロケール翻訳、数値は `Math.round` で整数表示、`nameParam()` による polity/province/person/role 名のロケール解決
  - EntityLinks: イベントの `entityRefs` から関連エンティティのリンクボタンを表示
  - 日付表示: `year/weekOfYear` 形式
- **Sidebar**: 国家一覧（rank 別）/ 家系一覧（支配家 / 無領家）/ 人物一覧（重要度順）/ 派閥一覧 / 外交劇一覧。ウォッチリスト対応
  - FactionRow（v0.21）: 指導者名・結成日（年/月/月内週）・メンバー数。翻訳済み
  - PlayRow（v0.21）: 種別・ステータス・initiator/defender 名・進展/緊張/期限。翻訳済み
- **ConfigPanel**: シミュレーションパラメータをリアルタイム調整
